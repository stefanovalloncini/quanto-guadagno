# Percentili di reddito netto — verifica dati

Le soglie usate dalla pagina Statistiche per collocare un netto annuo nella distribuzione italiana.

## Soglie (valori 2023, espressi in netto annuo)

| Percentile | Soglia |
|-----------|--------|
| Bottom 1% | 0 € |
| Bottom 10% | 15.000 € |
| Bottom 20% | 22.000 € |
| Mediana (50%) | 28.000 € |
| Top 30% | 33.000 € |
| Top 20% | 35.000 € |
| Top 10% | 45.000 € |
| Top 5% | 55.000 € |
| Top 1% | 100.000 € |

I valori sono espressi in netto annuo per facilitare il confronto con il calcolatore stipendio.

## Note

- I dati sono indicativi del lavoro dipendente e autonomo combinati.
- Le soglie cambiano lentamente; un aggiornamento annuale è sufficiente.
- Il "netto" qui si intende dopo IRPEF e contributi, prima di eventuali addizionali e fringe benefit.
